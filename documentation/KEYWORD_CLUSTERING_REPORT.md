# 🔍 Отчет о новой системе кластеризации с предварительной группировкой

## 🎯 **Цель улучшения**
Реализовать двухэтапную кластеризацию с предварительной группировкой по ключевым словам для повышения точности и качества кластеров.

## 🏗️ **Новая архитектура кластеризации**

### **До улучшения:**
```
Анонсы → LLM-кластеризация → Объединение кластеров
```

### **После улучшения:**
```
Анонсы → Предварительная группировка по ключевым словам → LLM-кластеризация внутри групп → Объединение кластеров
```

## 🔧 **Технические компоненты**

### **1. KeywordGrouper - предварительная группировка:**
- **Тематические ключевые слова** (10 основных тем)
- **Географические ключевые слова** (10 регионов Испании)
- **Временные ключевые слова** (срочность, периоды)
- **Алгоритм оценки принадлежности** к темам

### **2. Улучшенный NewsClusteringPipeline:**
- **Интеграция с KeywordGrouper**
- **Трехэтапная обработка**
- **Оптимизированные батчи** (75 анонсов)
- **Кэширование системных промптов**

## 📊 **Тематические категории**

### **Основные темы (10 категорий):**
1. **миграция_внж** - ВНЖ, документы, миграция
2. **налоги_финансы** - Налоги, банки, кредиты, пенсии
3. **здравоохранение** - Медицина, страховка, лечение
4. **образование** - Школы, курсы, языки, обучение
5. **недвижимость** - Жилье, аренда, покупка, ипотека
6. **транспорт** - Общественный транспорт, права, дороги
7. **культура_развлечения** - Фестивали, музеи, рестораны
8. **погода_климат** - Прогнозы, температура, сезоны
9. **политика_законы** - Правительство, реформы, выборы
10. **работа_карьера** - Вакансии, бизнес, предприниматели

### **Географические регионы (10 областей):**
- **Мадрид** - Столица, центральная Испания
- **Барселона** - Каталония
- **Валенсия** - Валенсийское сообщество

- **Пальма** - Майорка, Балеарские острова
- **Лас Пальмас** - Канарские острова

### **Временные категории (4 типа):**
- **срочно** - Экстренные, критические новости
- **сегодня** - Новости за последние дни
- **месяц** - Месячные тренды и события
- **год** - Годовые изменения и реформы

## 🚀 **Алгоритм работы**

### **Этап 1: Предварительная группировка**
```
1. Извлечение ключевых слов из заголовка и описания
2. Вычисление оценок принадлежности к темам
3. Определение географической принадлежности
4. Оценка временной срочности
5. Группировка по формуле: {тема}_{регион}
```

### **Этап 2: LLM-кластеризация внутри групп**
```
1. Обработка каждой предварительной группы отдельно
2. Разбивка больших групп на батчи по 75 анонсов
3. LLM-кластеризация с кэшированным промптом
4. Создание тематических кластеров
```

### **Этап 3: Объединение похожих кластеров**
```
1. Анализ созданных кластеров
2. Поиск пересечений и дублирований
3. Объединение логически связанных кластеров
4. Финальная оптимизация
```

## 🎯 **Критерии качества**

### **Оптимальный размер кластера:**
- **Минимум**: 2 новости (логическая связь)
- **Максимум**: 8 новостей (читаемость)
- **Идеал**: 3-6 новостей в кластере

### **Тематическая связность:**
- **Высокая**: Новости об одном событии
- **Средняя**: Новости одной темы в одном регионе
- **Низкая**: Разные темы или регионы

### **Географическая точность:**
- **Точная**: Новости из одного города/региона
- **Приблизительная**: Новости из соседних регионов
- **Общая**: Новости по всей Испании

## 🔍 **Алгоритм оценки принадлежности**

### **Формула расчета:**
```python
# Тематическая оценка
topic_score = matching_keywords / total_topic_keywords

# Географическая оценка  
geo_score = matching_geo_keywords / total_geo_keywords

# Временная оценка
time_score = matching_time_keywords / total_time_keywords

# Общая оценка
total_score = topic_score + geo_score + time_score
```

### **Пороги группировки:**
- **Минимальный порог темы**: 0.1 (10% совпадений)
- **Группировка**: {тема}_{регион}
- **Негруппированные**: "разное_общие"
