# 🧠 Отчет о внедрении умного выбора постов

## 🎯 **Цель изменения**
Создать алгоритм выбора постов по рейтингу с тематическим разнообразием, увеличить лимит до 8 постов в день (не считая срочных).

## 📊 **До изменения**
- **Архитектура**: Простой выбор по рейтингу без учета разнообразия
- **Проблемы**: 
  - Лимит 6 постов в день
  - Возможность публикации однотипных новостей подряд
  - Неравномерное распределение по времени
  - Отсутствие аналитики выбора постов

## 📊 **После изменения**
- **Архитектура**: Умный выбор с учетом разнообразия тем и времени
- **Преимущества**:
  - Лимит увеличен до 8 постов в день
  - Тематическое разнообразие с группировкой категорий
  - Равномерное распределение по временным слотам
  - Аналитика и предложения по оптимизации

```python
def _calculate_diversity_score(self, article: Dict[str, Any], 
                             selected_categories: List[str], 
                             selected_groups: List[str]) -> float:

    Рассчитывает оценку разнообразия для статьи:
    - Штраф за повторение категории (-0.5)

    - Бонус за новую группу (+0.4)
    - Бонус за редкую категорию (+0.2)
    """
```

### **3. Алгоритм распределения по времени**
```python
def _calculate_time_spread_score(self, article: Dict[str, Any], 
                               selected_times: List[str]) -> float:
    """
    Рассчитывает оценку распределения по времени:
    - Анализ утренних (09-11), дневных (14-16), вечерних (20-22) слотов
    - Бонус за равномерное распределение
    - Штраф за концентрацию в одном временном блоке
    """
```

### **4. Финальная оценка выбора**
```python
def _calculate_final_selection_score(self, article: Dict[str, Any], 
                                   diversity_score: float, 
                                   time_spread_score: float) -> float:
    """
    Комбинированная оценка для выбора статьи:
    final_score = (1 - diversity_weight - time_spread_weight) * base_score +
                  diversity_weight * diversity_score +
                  time_spread_weight * time_spread_score
    """
```

## 📊 **Формулы расчета**

### **Оценка разнообразия:**
```python
diversity_score = 1.0 - category_penalty - group_penalty + group_bonus + rarity_bonus

где:
- category_penalty = 0.5 (если категория уже выбрана)
- group_penalty = 0.3 (если группа уже выбрана)
- group_bonus = 0.4 (если новая группа)
- rarity_bonus = 0.2 - (частота_категории * 0.1)
```

### **Оценка распределения по времени:**
```python
time_counts = [morning_count, afternoon_count, evening_count]
max_count = max(time_counts)
min_count = min(time_counts)

if max_count == 0:
    spread_score = 1.0
else:
    spread_score = 1.0 - (max_count - min_count) / max_count
```

### **Финальная оценка выбора:**
```python
final_score = (1 - 0.3 - 0.2) * base_score + 0.3 * diversity_score + 0.2 * time_spread_score

где:
- base_score = рейтинг статьи / 100
- diversity_score = оценка разнообразия (0..1)
- time_spread_score = оценка распределения по времени (0..1)
```

## 🚀 **Логика выбора**

### **Приоритеты выбора:**
1. **Срочные посты** - размещаются первыми, не тратят лимит
2. **Высокий рейтинг** - базовый критерий качества
3. **Тематическое разнообразие** - избегаем повторений категорий
4. **Распределение по времени** - равномерно по всему дню

### **Правила разнообразия:**
- **Категории**: Не публикуем подряд 2 новости одной категории
- **Группы**: Предпочитаем новые группы категорий
- **Редкость**: Бонус за редко используемые категории

### **Правила времени:**
- **Утро**: 3 слота (09:00, 10:00, 11:00)
- **День**: 3 слота (14:00, 15:00, 16:00)
- **Вечер**: 2 слота (20:00, 21:00)
- **Равномерность**: Бонус за сбалансированное распределение
