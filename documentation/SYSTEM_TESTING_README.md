# 🧪 Система тестирования "Испания, ¿qué pasa?"

Комплексная система тестирования для проверки всех компонентов информационного портала для русскоязычных мигрантов в Испании.

## 📋 Обзор

Система включает в себя несколько уровней тестирования:

1. **Минимальные тесты** - быстрая проверка основных функций без внешних API
2. **Полные тесты** - комплексная проверка всех компонентов с внешними зависимостями
3. **Интеграционные тесты** - проверка взаимодействия между компонентами

## 🚀 Быстрый старт

### 1. Проверка окружения

```bash
python run_system_tests.py --check-env
```

### 2. Запуск минимальных тестов (рекомендуется для начала)

```bash
python run_system_tests.py --type minimal
```

### 3. Запуск всех тестов

```bash
python run_system_tests.py --type all
```

## 📁 Файлы тестирования

| Файл | Описание |
|------|----------|
| `run_system_tests.py` | Главный скрипт для запуска тестов |
| `test_system_minimal.py` | Минимальные тесты (быстрые) |
| `test_full_system_integration.py` | Полные тесты (медленные) |
| `system_test.log` | Лог полных тестов |
| `minimal_test.log` | Лог минимальных тестов |
| `*_test_report_*.json` | JSON отчеты о тестировании |

## 🔍 Типы тестирования

### Minimal (Минимальные тесты)
- ⏱️ **Время**: ~30 секунд
- 🔌 **Зависимости**: Только локальные файлы
- ✅ **Что проверяется**:
  - Структура файлов проекта
  - Импорт всех модулей
  - Создание экземпляров классов
  - Базовая функциональность компонентов
  - Структура веб-сайта

### Full (Полные тесты)
- ⏱️ **Время**: ~5-10 минут
- 🔌 **Зависимости**: Все внешние API
- ✅ **Что проверяется**:
  - Все функции минимальных тестов
  - RSS парсинг реальных фидов
  - Подключение к Firebase
  - OpenAI API интеграция
  - Telegram бот интеграция
  - Кластеризация новостей
  - Приоритизация статей
  - Полный workflow обработки

### Quick (Быстрые тесты)
- ⏱️ **Время**: ~30 секунд
- 🔌 **Зависимости**: Минимальные
- ✅ **Что проверяется**: То же, что и в минимальных тестах

### All (Все тесты)
- ⏱️ **Время**: ~10-15 минут
- 🔌 **Зависимости**: Все
- ✅ **Что проверяется**: Последовательный запуск всех типов тестов

## 🧩 Компоненты системы

### 1. RSS Parser (`rss_parser.py`)
- Парсинг RSS-лент
- Извлечение полного текста статей
- Фильтрация через LLM
- Перевод и адаптация контента

### 2. Content Generator (`content_generator.py`)
- Генерация статей для сайта
- Создание Telegram-постов
- Использование OpenAI API

### 3. News Clustering (`news_clustering.py`)
- Группировка похожих новостей
- Создание кластеров
- Анализ тем

### 4. Prioritization (`prioritization_llm.py`)
- Приоритизация статей
- Оценка важности новостей
- Использование LLM для анализа

### 5. Jobs Scheduler (`jobs_scheduler.py`)
- Планировщик задач
- Управление очередью публикаций
- Автоматическое постинг

### 6. Publication Scheduler (`publication_scheduler.py`)
- Планировщик публикаций
- Управление временными окнами
- Telegram интеграция

### 7. Firebase Client (`firebase_client.py`)
- Работа с Firebase
- Хранение данных
- Управление настройками

### 8. Article Exporter (`article_exporter.py`)
- Экспорт статей в Markdown
- Интеграция с Astro сайтом
- Управление контентом

### ❌ Ошибки

### ⚠️ Предупреждения
```
⚠️ Environment File: .env файл не найден, используйте env_example.txt как шаблон
⚠️ OpenAI API Key: OPENAI_API_KEY не найден в переменных окружения
```

## 🔧 Настройка окружения

### 1. Переменные окружения
Создайте файл `.env` на основе `env_example.txt`:

```bash
# OpenAI API
OPENAI_API_KEY=your_openai_api_key

# Telegram
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка Firebase
1. Создайте проект в Firebase Console
2. Скачайте ключ сервисного аккаунта
3. Сохраните как `firebase_key.json`

## 🚨 Устранение проблем

### Частые ошибки

#### 1. Отсутствуют файлы
```
❌ File: rss_parser.py: Файл не найден
```
**Решение**: Убедитесь, что все файлы проекта находятся в текущей директории.

#### 2. Ошибки импорта
```
❌ Import: module.Class: Ошибка импорта: No module named 'module'
```
**Решение**: Установите недостающие зависимости:
```bash
pip install -r requirements.txt
```

#### 3. Проблемы с Firebase
```
❌ Firebase Connection Test: Ошибка подключения
```
**Решение**: 
- Проверьте наличие `firebase_key.json`
- Убедитесь в правильности настроек Firebase
- Проверьте интернет-соединение

#### 4. Проблемы с OpenAI API
```
⚠️ OpenAI API Key: OPENAI_API_KEY не найден
```
**Решение**: Добавьте API ключ в файл `.env`

#### 5. Проблемы с Telegram
```
⚠️ Telegram Token: TELEGRAM_BOT_TOKEN не найден
```
**Решение**: Добавьте токен бота в файл `.env`

## 🔄 Автоматизация тестирования

### Cron job для регулярного тестирования
```bash
# Добавьте в crontab для ежедневного тестирования в 9:00
0 9 * * * cd /path/to/project && python run_system_tests.py --type minimal >> /var/log/system_tests.log 2>&1
```

### CI/CD интеграция
```yaml
# GitHub Actions пример
name: System Tests
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v2
    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.9'
    - name: Install dependencies
      run: pip install -r requirements.txt
    - name: Run minimal tests
      run: python run_system_tests.py --type minimal
```
