## 🏗️ Архитектура решения

### Структура настроек

```json
{
  "publishing_windows": [
    {"start": "09:00", "end": "11:00"},
    {"start": "14:00", "end": "16:00"},
    {"start": "20:00", "end": "22:00"}
  ],
  "max_articles_per_window": 2,
  "min_post_interval_minutes": 30,
  "telegram_chat_id": "@your_channel"
}
```

### Алгоритм работы

1. **Получение настроек** из Firebase
2. **Поиск неопубликованных статей** с `telegram_post != None`
3. **Сортировка по приоритету** (`priority_score DESC`, `created_at ASC`)
4. **Обработка каждой статьи:**
   - Проверка срочности (`urgent = true`)
   - Проверка текущего окна публикации
   - Проверка интервала с последней публикацией
   - Проверка лимита публикаций в окне
   - Отправка в Telegram
   - Обновление статуса статьи

### Логика приоритетов

1. **Срочные статьи** (`urgent = true`) - всегда публикуются
2. **Обычные статьи** - только в активных окнах
3. **Сортировка** по `priority_score` (по убыванию)
4. **При равном приоритете** - по времени создания
