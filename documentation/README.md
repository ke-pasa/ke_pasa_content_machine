# Испания, ¿qué pasa? - Информационный портал для русскоязычных мигрантов

Современный новостной портал, созданный на базе Astro, для русскоязычных мигрантов в Испании. Сайт предоставляет актуальную информацию о новостях, статьях, гайдах и полезных материалах для жизни в Испании.

## 🚀 Особенности

### ✨ Основной функционал
- **Современный дизайн** с адаптивной версткой
- **10 категорий новостей** с цветовой кодировкой
- **SEO-оптимизация** с поддержкой Open Graph и Twitter Cards
- **Интеграция с Telegram** - ссылки на посты в конце статей
- **Система тегов** для удобной навигации
- **Пагинация** для больших списков статей
- **Темная/светлая тема** (автоматическое переключение)

### 📱 Адаптивность
- Полностью адаптивный дизайн
- Оптимизация для мобильных устройств
- Быстрая загрузка страниц
- Современные CSS-переменные

### 🎨 Дизайн
- Современный минималистичный дизайн
- Градиентные элементы и тени
- Анимации и переходы
- Иконки эмодзи для категорий
- Профессиональная типографика

## 📝 Структура frontmatter

Каждая статья должна содержать следующий frontmatter:

```yaml
---
title: "Название статьи"
description: "Краткое описание статьи"
pubDate: "2025-01-15"
author: "Автор статьи"
image: "/images/news/filename.jpg"
slug: "url-slug"
category: "migration"
tags: ["тег1", "тег2", "тег3"]
seo:
  title: "SEO-заголовок"
  description: "SEO-описание"
  keywords: ["ключевое слово", "второе"]
telegram_post: "https://t.me/spain_que_pasa/123"
---
```

### Поля frontmatter:

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `title` | string | ✅ | Заголовок статьи |
| `description` | string | ✅ | Краткое описание |
| `pubDate` | date | ✅ | Дата публикации |
| `author` | string | ❌ | Автор статьи |
| `image` | string | ❌ | Путь к изображению |
| `slug` | string | ❌ | URL-слаг (автогенерируется) |
| `category` | string | ❌ | Категория из списка |
| `tags` | array | ❌ | Массив тегов |
| `seo.title` | string | ❌ | SEO-заголовок |
| `seo.description` | string | ❌ | SEO-описание |
| `seo.keywords` | array | ❌ | SEO-ключевые слова |
| `telegram_post` | string | ❌ | Ссылка на Telegram пост |

## 🛠️ Установка и запуск

### Предварительные требования
- Node.js 18+ 
- npm или yarn

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```

Сайт будет доступен по адресу: http://localhost:4321

### Сборка для продакшена
```bash
npm run build
```

### Предварительный просмотр сборки
```bash
npm run preview
```

## 🎨 Кастомизация

### Изменение цветовой схемы
Отредактируйте CSS-переменные в `src/styles/global.css`:

```css
:root {
  --color-primary: #3b82f6;
  --color-primary-dark: #1d4ed8;
  --color-secondary: #64748b;
  --color-accent: #f59e0b;
  /* ... другие цвета */
}
```

### Добавление новых категорий
1. Добавьте категорию в `src/consts.ts`
2. Обновите стили в `src/styles/global.css`
3. Создайте соответствующие статьи

### Изменение layout
Отредактируйте `src/layouts/BaseLayout.astro` для изменения общей структуры страниц.

## 🔧 Конфигурация

### Astro конфигурация (`astro.config.mjs`)
```javascript
export default defineConfig({
  site: 'https://spain-que-pasa.com',
  integrations: [mdx(), sitemap()],
  markdown: {
    shikiConfig: {
      theme: 'github-dark',
      wrap: true,
    },
  },
  vite: {
    resolve: {
      alias: {
        '@': '/src',
        '@components': '/src/components',
        '@layouts': '/src/layouts',
        '@styles': '/src/styles',
        '@assets': '/src/assets',
      },
    },
  },
});
```

### Контент конфигурация (`src/content.config.ts`)
Настройка схемы для валидации frontmatter статей.
