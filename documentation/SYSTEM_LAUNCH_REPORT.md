## 🔧 Исправленные критические ошибки

### 1. Проблема с парсингом JSON ответов от OpenAI
**Проблема**: OpenAI Batch API возвращал truncated JSON строки, что приводило к ошибкам `json.loads()`

**Решение**: Добавлен fallback механизм с regex для извлечения поля `result`:
```python
if isinstance(result_body, str):
    try:
        res = json.loads(result_body)
    except:
        # Regex fallback для truncated JSON
        match = re.search(r'"result":\s*"([^"]*)"', result_body)
        if match:
            res['result'] = match.group(1)
```

### 2. Смягчение фильтра
**Проблема**: Слишком строгий фильтр отклонял релевантные новости

**Решение**: Обновлен prompt с "мягким фильтром" и лучшими примерами:
- Добавлено правило "При малейшем сомнении выбирай ✅ Интересно"
- Обновлены примеры с TIE картами и минимальной зарплатой
- Процент одобрения вырос до оптимальных 21.1%
