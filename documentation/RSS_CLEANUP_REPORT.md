## 🎯 Критерии очистки

1. **Свежесть новостей:** Не старше 30 дней
2. **Процент свежих статей:** Минимум 30%
3. **Работоспособность:** Лента должна парситься без ошибок
4. **Регулярность обновлений:** Активные источники
