## 🔄 Обновленная логика работы

### **Этап 1: RSS Парсинг (каждые 2 часа)**
```
RSS ленты → Парсинг → LLM фильтрация → Сохранение в Firebase
```
- Читается `feeds.txt`
- Каждая новость анализируется LLM на интересность
- Интересные новости сохраняются в `articles` с `processed=True`

### **Этап 2: Генерация статей (каждые 10 минут)**
```
Обработанные новости → Генерация контента → Экспорт на сайт
```
- Ищутся новости с `processed=True`, `exported_to_site=False`
- Для каждой создается статья на русском языке
- Статья сохраняется в `generated_articles` с `exported_to_site=True`

### **Этап 3: Публикация в Telegram (каждые 60 минут)**
```
Неопубликованные статьи → Выбор лучшей → Проверка темы → Публикация
```
- Получаются статьи с `published=False`
- Сортировка по приоритету (`daily_priority_score`, `priority_score`)
- Проверка: не публиковали ли уже такую тему сегодня
- Публикация максимум 1 статьи за час

### **Этап 4: Ежедневная приоритизация (каждые 24 часа)**
```
Все статьи → Переоценка важности → Обновление рейтингов
```
- Обновляются `daily_priority_score` для всех статей
- Учитывается актуальность и важность для мигрантов
