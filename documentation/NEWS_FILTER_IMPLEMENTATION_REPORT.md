**Дата внедрения**: 20 августа 2025 года

**Цель**: Фильтрация новостей по интересу для ЦА с учетом региональных приоритетов  

## 🎯 ЦЕЛЬ СИСТЕМЫ ФИЛЬТРАЦИИ

Создать интеллектуальную систему оценки новостей, которая будет предсказывать:
1. **Насколько новость удивит ЦА**
2. **Даст ли важную информацию**
3. **Захочет ли ЦА поделиться**
4. **Релевантна ли для приоритетных регионов**

## 📊 СИСТЕМА ОЦЕНКИ (0-100 баллов)

### **1. РЕГИОНАЛЬНАЯ РЕЛЕВАНТНОСТЬ (0-10 баллов):**

### **2. УДИВЛЕНИЕ И ЭМОЦИИ (0-25 баллов):**

## 🎯 РЕКОМЕНДАЦИИ ПО ПУБЛИКАЦИИ

### **ПУБЛИКОВАТЬ (80-100 баллов):**
- Критически важные изменения в законах/документах
- Шокирующие новости с практическими последствиями
- События, которые затронут многих мигрантов
- Уникальные возможности для ЦА

### **КРАТКАЯ ЗАМЕТКА (60-79 баллов):**
- Интересные, но не критичные новости
- Культурные события в приоритетных регионах
- Открытие новых заведений/услуг для русскоязычных

### **НЕ ПУБЛИКОВАТЬ (0-59 баллов):**
- Общие фразы без конкретики
- Новости без практической пользы
- Устаревшие новости
- Дублирующий контент
- Нерелевантные темы
- Обычные погодные явления
