# 🔥 Настройка Firebase для RSS Parser

## 📋 Пошаговая инструкция

### 1. Создание проекта Firebase

1. Перейдите на [Firebase Console](https://console.firebase.google.com/)
2. Нажмите "Создать проект"
3. Введите название проекта (например: `spain-que-pasa`)
4. Отключите Google Analytics (не обязательно)
5. Нажмите "Создать проект"

### 2. Включение Firestore Database

1. В левом меню выберите "Firestore Database"
2. Нажмите "Создать базу данных"
3. Выберите "Начать в тестовом режиме" (для разработки)
4. Выберите ближайший регион (например: `europe-west1`)
5. Нажмите "Готово"

### 3. Создание сервисного аккаунта

1. В левом меню выберите "Настройки проекта" (⚙️)
2. Перейдите на вкладку "Сервисные аккаунты"
3. Нажмите "Создать новый закрытый ключ"
4. Выберите "JSON" и нажмите "Создать ключ"
5. Скачается файл с ключом

### 4. Настройка в проекте

1. Переименуйте скачанный файл в `firebase_key.json`
2. Поместите файл в корень проекта `spain-que-pasa/`
3. Убедитесь, что файл добавлен в `.gitignore` (для безопасности)

### 5. Структура данных

После настройки в Firestore автоматически создастся коллекция `articles` со следующей структурой:

```json
{
  "document_id": "md5_hash_of_link_and_title",
  "title": "Переведенный заголовок статьи",
  "description": "Описание статьи",
  "content": "Полный текст статьи",
  "tags": ["тег1", "тег2", "тег3"],
  "link": "https://original-article-url.com",
  "published": "2025-01-29",
  "image": "https://image-url.com",
  "category": "news",
  "source_feed": "Название RSS-ленты",
  "source_link": "https://original-article-url.com",
  "created_at": "2025-01-29T12:00:00"
}
```

### 6. Тестирование

Запустите тест Firebase:
```bash
python test_firebase.py
```

Если все настроено правильно, вы увидите:
```
✅ Firebase подключен успешно
```

### 7. Правила безопасности Firestore

Для продакшена настройте правила безопасности в Firestore:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /articles/{document} {
      allow read: if true;  // Разрешить чтение всем
      allow write: if false; // Запретить запись всем (только через админку)
    }
  }
}
```

## 🔒 Безопасность

- **Никогда не коммитьте** `firebase_key.json` в Git
- Добавьте файл в `.gitignore`:
  ```
  firebase_key.json
  ```
- Ограничьте права сервисного аккаунта только необходимыми операциями
- Регулярно ротируйте ключи

## 🛠️ Устранение неполадок

### Ошибка: "Permission denied"
- Проверьте права сервисного аккаунта
- Убедитесь, что Firestore включен
- Проверьте правила безопасности

### Ошибка: "Invalid key"
- Проверьте правильность файла `firebase_key.json`
- Убедитесь, что файл не поврежден
- Попробуйте скачать ключ заново

### Ошибка: "Project not found"
- Проверьте ID проекта в `firebase_key.json`
- Убедитесь, что проект существует и активен
