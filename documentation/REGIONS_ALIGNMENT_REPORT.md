# Отчет о выравнивании регионов между сайтом Astro и генератором статей

## Проблема
При проверке соответствия регионов между сайтом Astro (`spain-news-portal`) и генератором статей (`content_generator.py`) было обнаружено несоответствие в формате написания названий регионов.

## Обнаруженные различия

### ❌ **Было:**
- **Сайт Astro**: регионы написаны с заглавной буквы (`Andalusia`, `Catalonia`, `Madrid`)
- **Генератор статей**: регионы написаны в нижнем регистре (`andalusia`, `catalonia`, `madrid`)

### ✅ **Стало:**
- **Сайт Astro**: регионы написаны с заглавной буквы (`Andalusia`, `Catalonia`, `Madrid`)
- **Генератор статей**: регионы написаны с заглавной буквы (`Andalusia`, `Catalonia`, `Madrid`)

## Внесенные изменения

### 1. Обновлены промпты для LLM
В функции `generate_article()` обновлены промпты для обоих форматов:

**Markdown промпт:**
```
Верни это в поле "region" в правильном формате (с заглавной буквы). Если неясно — укажи "region": "unknown".
```

**JSON промпт:**
```
- region: регион Испании (в формате 'Andalusia', 'Catalonia', 'Madrid', 'Valencia', 'Galicia', 'Castile and León', 'Basque Country', 'Castile-La Mancha', 'Canary Islands', 'Murcia', 'Aragon', 'Extremadura', 'Balearic Islands', 'Asturias', 'Navarre', 'Cantabria', 'La Rioja', 'Ceuta', 'Melilla')
```

### 2. Обновлена функция fallback
В функции `_generate_fallback_markdown()` все возвращаемые значения регионов приведены к правильному формату:

```python
# Было:
region = "catalonia"
region = "madrid"
region = "andalusia"

# Стало:
region = "Catalonia"
region = "Madrid"
region = "Andalusia"
```
