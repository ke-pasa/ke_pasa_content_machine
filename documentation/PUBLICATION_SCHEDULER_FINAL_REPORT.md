## 📊 ПРИМЕРЫ РАБОТЫ

### Срочная публикация
```python
# Немедленная публикация срочной новости
urgent_job = scheduler.schedule_urgent(urgent_cluster)
# Результат: urgent_post_sample_urgent_1_2025-08-03_17-35
```

### Планирование на день
```python
# Планирование публикаций на завтра
jobs = scheduler.schedule_publications(clusters, "2025-08-04")
# Результат: 4 публикации (2 обычных + 1 дайджест + 1 срочная)
```

### Создание дайджеста
```python
# Автоматическое создание дайджеста
digest_job = scheduler.create_digest_job(unused_clusters, date)
# Результат: digest_2025-08-04 с 5 кластерами
```

## 🎯 СТРАТЕГИЯ ПЛАНИРОВАНИЯ

### ✅ Реализованная логика
1. **Срочные новости** - публикуются немедленно (urgent_post)
2. **Обычные новости** - по расписанию 09:00, 14:00, 20:00
3. **Дайджест** - в 21:30 из неиспользованных кластеров
4. **Ограничения** - максимум 2 статьи на пост, порог приоритета 60
5. **Антидублирование** - проверка существующих jobs
6. **Чувствительность** - не более одного "high" sensitivity в день
7. **Event types** - избежание повторных типов событий
