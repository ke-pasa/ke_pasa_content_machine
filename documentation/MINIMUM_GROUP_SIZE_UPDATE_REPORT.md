# 🔧 Отчет об изменении минимального размера группы для LLM кластеризации

## 🎯 **Цель изменения**
Увеличить минимальный размер группы для LLM кластеризации с 2 до 3 анонсов для улучшения качества кластеризации.

## 📊 **До изменения**
- **Минимальный размер группы**: 2 анонса
- **Логика**: Группы с 1-2 анонсами отправлялись в LLM
- **Результат**: Много мелких кластеров низкого качества

## 📊 **После изменения**
- **Минимальный размер группы**: 3 анонса
- **Логика**: Группы с <3 анонсами пропускаются
- **Результат**: Только качественные группы с достаточным количеством данных

## 🔧 **Технические изменения**

### **1. Изменение в `news_clustering.py`**
```python
# БЫЛО:
if len(group_announcements) < 2:
    print(f"   ⚠️  Группа '{group_name}' слишком мала ({len(group_announcements)} анонсов), пропускаю")
    continue

# СТАЛО:
if len(group_announcements) < 3:
    print(f"   ⚠️  Группа '{group_name}' слишком мала ({len(group_announcements)} анонсов), пропускаю")
    continue
```
