# Система приоритизации новостных кластеров

## Обзор

Модуль `prioritization_llm.py` реализует автоматическую оценку и приоритизацию новостных кластеров перед публикацией с помощью LLM (OpenAI GPT-4o-mini). Система действует как редактор и стратег, определяя важность, срочность и чувствительность новостей для русскоязычных мигрантов в Испании.

## Архитектура

### Основные компоненты

1. **NewsPrioritizer** - основной класс для приоритизации
2. **LLM Integration** - интеграция с OpenAI API
3. **JSON Processing** - обработка структурированных данных
4. **Fallback Logic** - резервная логика при ошибках

### Ключевые методы

- `prioritize_clusters()` - основная функция приоритизации
- `get_high_priority_clusters()` - фильтрация высокоприоритетных кластеров
- `get_urgent_clusters()` - фильтрация срочных кластеров
- `get_publishable_clusters()` - фильтрация кластеров для публикации

## Критерии оценки

### 🔘 publish (boolean)
- **true** - новость связана с жизнью мигрантов, Испанией, полезна, важна, актуальна
- **false** - нерелевантна, старая, частная история без пользы, не связана с Испанией

### 🔴 urgent (boolean)
- **true** - важно опубликовать немедленно (катастрофы, землетрясения, экстренные изменения законов)
- **false** - можно ждать

### 🟢 evergreen (boolean)
- **true** - материал будет актуален через недели/месяцы (инструкции, гайды, законы)
- **false** - быстро устареет или связан с конкретной датой

### 🏷️ event_type (string)
Одно из значений:
- `emergency` - чрезвычайные ситуации
- `weather_alert` - погодные предупреждения
- `policy_change` - изменения политики
- `crime` - преступления
- `social_issue` - социальные проблемы
- `migration_tip` - советы по миграции
- `local_event` - местные события
- `scam_alert` - предупреждения о мошенничестве
- `economic_news` - экономические новости
- `health` - здоровье
- `legal` - правовые вопросы
- `education` - образование
- `transport` - транспорт
- `entertainment` - развлечения

### 📊 priority_score (0-100)
Оценка влияния темы на жизнь мигрантов:
- **0-30** - низкий приоритет (частные случаи)
- **31-60** - средний приоритет
- **61-80** - высокий приоритет
- **81-100** - критический приоритет (массовые события)

### 📝 priority_reason (string)
Краткое объяснение оценки приоритета

### 🔐 sensitivity_level (string)
- `normal` - нет деликатных тем
- `sensitive` - миграционные конфликты, протесты, политика
- `high` - насилие, смерть, трагедии, расизм

## Промпт для LLM

Система использует детальный промпт, который включает:

1. **Роль и контекст** - редактор для русскоязычных мигрантов в Испании
2. **Критерии оценки** - подробное описание всех полей
3. **Примеры значений** - для каждого типа поля
4. **Инструкции** - строгие требования к формату ответа
5. **Входные данные** - JSON с кластерами для оценки

## Обработка ошибок

### Стратегии fallback

1. **JSON Parsing Errors** - дефолтные значения для всех полей
2. **LLM API Errors** - возврат исходных кластеров с дефолтами
3. **Missing Fields** - автоматическое добавление отсутствующих полей
4. **Markdown Wrapping** - автоматическое удаление markdown оберток

## Интеграция с системой

### Использование в RSS Parser

```python

# Создание приоритизатора
prioritizer = create_prioritizer(openai_client, db)

# Приоритизация кластеров
prioritized_clusters = prioritizer.prioritize_clusters(clusters)

# Фильтрация по приоритету
high_priority = prioritizer.get_high_priority_clusters(prioritized_clusters, min_score=70)
urgent = prioritizer.get_urgent_clusters(prioritized_clusters)
publishable = prioritizer.get_publishable_clusters(prioritized_clusters)
```
