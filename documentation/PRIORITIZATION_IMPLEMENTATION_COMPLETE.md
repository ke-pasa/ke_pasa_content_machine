# Отчет о завершении: Система приоритизации новостных кластеров

## ✅ Задача выполнена

Реализована система автоматической оценки и приоритизации новостных кластеров с помощью LLM для новостного ИИ-бота русскоязычных мигрантов в Испании.

## 📋 Что было реализовано

### 1. Основной модуль `prioritization_llm.py`

**Класс NewsPrioritizer:**
- Автоматическая оценка кластеров по 7 критериям
- Интеграция с OpenAI GPT-4o-mini
- Обработка JSON ответов с fallback логикой
- Фильтрация по приоритету, срочности и публикации

**Ключевые методы:**
- `prioritize_clusters()` - основная функция приоритизации
- `get_high_priority_clusters()` - фильтрация высокоприоритетных (≥70 баллов)
- `get_urgent_clusters()` - фильтрация срочных новостей
- `get_publishable_clusters()` - фильтрация для публикации

### 2. Критерии оценки

**7 основных полей:**
- `publish` (boolean) - публиковать ли новость
- `urgent` (boolean) - срочность публикации
- `evergreen` (boolean) - долгосрочная актуальность
- `event_type` (string) - тип события (14 категорий)
- `priority_score` (0-100) - балл приоритета
- `priority_reason` (string) - объяснение оценки
- `sensitivity_level` (string) - уровень чувствительности

### 3. Типы событий (event_type)

1. `emergency` - чрезвычайные ситуации
2. `weather_alert` - погодные предупреждения
3. `policy_change` - изменения политики
4. `crime` - преступления
5. `social_issue` - социальные проблемы
6. `migration_tip` - советы по миграции
7. `local_event` - местные события
8. `scam_alert` - предупреждения о мошенничестве
9. `economic_news` - экономические новости
10. `health` - здоровье
11. `legal` - правовые вопросы
12. `education` - образование
13. `transport` - транспорт
14. `entertainment` - развлечения

### 4. Уровни чувствительности

- `normal` - нет деликатных тем
- `sensitive` - миграционные конфликты, протесты, политика
- `high` - насилие, смерть, трагедии, расизм

### 5. Промпт для LLM

Детальный промпт включает:
- Роль редактора для русскоязычных мигрантов
- Подробные критерии оценки
- Примеры для каждого поля
- Строгие инструкции по формату ответа
- Требование только JSON без markdown

### 6. Обработка ошибок

**Fallback стратегии:**
- JSON parsing errors → дефолтные значения
- LLM API errors → возврат исходных данных с дефолтами
- Missing fields → автоматическое добавление
- Markdown wrapping → автоматическое удаление

**Дефолтные значения:**
```python
{
    'publish': True,
    'urgent': False,
    'evergreen': False,
    'event_type': 'local_event',
    'priority_score': 50,
    'priority_reason': 'Автоматическая оценка (ошибка LLM)',
    'sensitivity_level': 'normal'
}
```
