## 🚀 Ключевые возможности

### 1. Двойной формат вывода
```python
# JSON формат (по умолчанию)
article_json = generate_article(cluster, as_markdown=False)

# Markdown формат
article_md = generate_article(cluster, as_markdown=True)
```

### 2. SEO-оптимизация
- **keywords:** 3-5 однословных существительных
- **tags:** однословные значения для категоризации
- **category:** выбор из предопределенного списка
- **slug:** URL-дружественная версия заголовка

### 3. Astro совместимость
```markdown
---
title: "Заголовок статьи"
description: "Описание статьи"
pubDate: "2025-01-03"
author: "Авто-редакция"
tags: [миграция, жильё, налоги]
keywords: [миграция, жильё, налоги]
category: "society"
slug: "kak-iskat-kvartiru-v-barcelone"
image: "https://example.com/image.jpg"
---

## Содержание статьи
```

## 💡 Примеры использования

