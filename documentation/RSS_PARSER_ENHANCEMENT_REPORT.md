## 🚨 Известные проблемы и решения

### Проблема 1: ElDiario.es ленты
**Симптом:** `<unknown>:2:0: syntax error`  
**Причина:** Некорректный XML формат в ответе сервера  
**Решение:** Используется CloudScraper + очистка XML, но не всегда помогает  
**Обходной путь:** Использовать `https://www.eldiario.es/rss` (общая лента)

### Проблема 2: El País политика
**Симптом:** `HTTP 370`  
**Причина:** Лента удалена или перемещена  
**Решение:** Исключена из обновленного списка  
**Альтернатива:** Другие разделы El País работают нормально

### Проблема 3: Некоторые региональные ленты
**Симптом:** `syntax error` или `mismatched tag`  
**Причина:** Нестандартный HTML вместо XML  
**Решение:** Улучшенная очистка XML + обработка HTML entities
