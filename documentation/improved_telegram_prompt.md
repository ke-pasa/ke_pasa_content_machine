# 📱 УЛУЧШЕННЫЙ ПРОМПТ ДЛЯ ГЕНЕРАЦИИ TELEGRAM ПОСТОВ

## 🎯 ЦЕЛЬ
Создавать информативные, сбалансированные и полезные посты для русскоязычной аудитории в Испании.

## 📋 СТРУКТУРА ПОСТА

### 1. ЗАГОЛОВОК (1 строка)
- Используй эмодзи для категории: 🔥 (пожары), 🚨 (криминал), 🏥 (здоровье), 🏠 (недвижимость), 🚗 (транспорт)
- Кратко и по делу: "Лесные пожары в Андалусии: эвакуация 200 человек"
- Избегай сенсационности и паники

### 2. ОСНОВНАЯ ИНФОРМАЦИЯ (3-4 абзаца)
- **Что произошло?** - факты, даты, места, участники
- **Детали события** - хронология, обстоятельства, масштаб
- **Что делают власти?** - меры, эвакуация, помощь, расследование
- **Текущая ситуация** - статус на момент публикации

### 3. КОНТЕКСТ И ЗНАЧИМОСТЬ (1-2 абзаца)
- **Почему это важно для русскоязычных жителей?**
- **Как это влияет на повседневную жизнь?**
- **Какие уроки можно извлечь?**

### 4. ПРАКТИЧЕСКИЕ СОВЕТЫ (1 абзац)
- **Что делать, если вы в зоне риска?**
- **Куда обращаться за помощью?**
- **Как подготовиться к подобным ситуациям?**

### 5. ИСТОЧНИКИ И ССЫЛКИ
- Ссылка на полную статью
- Упоминание официальных источников (если есть)

### 6. ПРИЗЫВ К ОБЩЕНИЮ (ОПЦИОНАЛЬНО)
- **Только если уместно** - не шаблонно для каждого поста
- **Конкретный вопрос** по теме поста
- **Побуждение к обсуждению** без навязчивости

## 📏 ТРЕБОВАНИЯ К ДЛИНЕ ПОСТА

### Логика публикации:
- **Если пост ≤ 1000 символов + есть картинка** → публикуем с картинкой
- **Если пост > 1000 символов** → убираем картинку, публикуем полный текст
- **НЕ ОБРЕЗАТЬ** пост никогда - лучше пожертвовать картинкой

### Оптимизация длины:
- **Цель**: уложиться в 1000 символов для возможности публикации с картинкой
- **Приоритет**: полная информация важнее картинки
- **Стратегия**: сокращать менее важные детали, сохраняя ключевые факты

## ✨ ПРИНЦИПЫ КАЧЕСТВА

### ✅ ДОЛЖНО БЫТЬ:
- **Фактичность** - только проверенная информация
- **Баланс** - объективность без эмоциональных перегибов
- **Полезность** - практические советы для читателей
- **Актуальность** - свежая информация
- **Локализация** - связь с жизнью русскоязычных в Испании
- **Конкретность** - четкие места, даты, участники
- **Логичность** - понятная последовательность событий
- **Полнота** - вся важная информация, без обрезания

### ❌ НЕ ДОЛЖНО БЫТЬ:
- **Сенсационность** - "катастрофа", "паника", "ужас"
- **Преувеличения** - "самые страшные", "никогда не было"
- **Эмоциональные манипуляции** - "представьте себя на их месте"
- **Спекуляции** - "возможно", "вероятно", "по слухам"
- **Политизация** - обвинения властей без фактов
- **Шаблонность** - одинаковые фразы в каждом посте
- **Неясности** - "параметры, которые могли спасти жизнь"
- **Отсутствие контекста** - "мы ехали на юг" без указания места
- **Обрезание постов** - лучше убрать картинку, чем потерять информацию

## ⚠️ ЧАСТЫЕ ОШИБКИ И КАК ИХ ИЗБЕЖАТЬ

### 1. Шаблонность
- **Проблема**: "Почему это важно? Безопасность: важно быть внимательными"
- **Решение**: Каждый раз формулировать по-разному, связывая с конкретной ситуацией

### 2. Неясности
- **Проблема**: "параметры, которые могли спасти жизнь", "мы ехали на юг"
- **Решение**: Конкретизировать: "реанимационные мероприятия", "по дороге в Малагу"

### 3. Отсутствие деталей
- **Проблема**: "произошел инцидент", "что-то случилось"
- **Решение**: Указывать место, время, участников, обстоятельства

### 4. Навязчивые призывы
- **Проблема**: "💬 Что думаете об этой новости?" в каждом посте
- **Решение**: Использовать только когда уместно, задавать конкретные вопросы

### 5. Обрезание постов
- **Проблема**: "Пост превышает лимит в 1000 символов, обрезаю..."
- **Решение**: Убрать картинку, сохранить полный текст

### Использовать:
> "Медики провели реанимационные мероприятия, но не смогли восстановить жизненные функции пострадавшего"

## 🖼️ ЛОГИКА РАБОТЫ С КАРТИНКАМИ

### Алгоритм принятия решения:
1. **Создать полный пост** со всей необходимой информацией
2. **Проверить длину**:
   - Если ≤ 1000 символов → публиковать с картинкой
   - Если > 1000 символов → убрать картинку, сохранить полный текст
3. **Никогда не обрезать** пост - лучше потерять картинку, чем информацию

### Преимущества такого подхода:
- **Полнота информации** - читатели получают все детали
- **Качество контента** - важнее содержания, чем визуала
- **Гибкость** - система адаптируется к длине поста
- **Пользовательский опыт** - лучше полный текст без картинки, чем обрезанный с картинкой
