# 📊 Система кластеризации новостей

## 🎯 Обзор

Реализована 2-этапная система кластеризации новостных анонсов с использованием OpenAI GPT-4o-mini. Система группирует похожие новости по смыслу и создает объединенные статьи для более эффективной публикации.

## 🏗️ Архитектура

### Основные компоненты:

1. **`NewsCluster`** - класс для представления кластера новостей
2. **`NewsClusteringPipeline`** - основной пайплайн кластеризации
3. **Интеграция с `RSSParser`** - методы для работы с кластеризацией

### 2-этапный процесс:

#### Этап 1: Кластеризация в батчах
- Разбивает анонсы на батчи по 20 штук
- Для каждого батча выполняет семантическую кластеризацию
- Использует LLM для группировки по смыслу

#### Этап 2: Объединение похожих кластеров
- Сравнивает кластеры между собой
- Объединяет схожие темы
- Создает финальный список кластеров

## 🤖 LLM Промпты

### Этап 1: Кластеризация батча
```
Ты журналист. Ниже {len(batch)} новостных анонсов.

Сгруппируй их по смыслу — новости об одном и том же событии должны быть в одном кластере.

**ПРАВИЛА КЛАСТЕРИЗАЦИИ:**
- Объединяй новости об одном событии/теме
- Учитывай географическую близость (например, новости из одного города)
- Учитывай временную близость (новости за последние дни)
- Разделяй разные аспекты одной темы (например, законопроект и его принятие)

**ФОРМАТ ОТВЕТА:**
Для каждого кластера создай объект с полями:
- "topic_summary": краткое описание темы (1-2 предложения)
- "sources": массив объектов с полями "title", "link", "summary"
- "combined_context": объединенный текст важных деталей из всех источников

**НОВОСТИ ДЛЯ КЛАСТЕРИЗАЦИИ:**
{announcements_text}

Ответь строго в формате JSON-массива объектов кластеров.
```

### Этап 2: Объединение кластеров
```
У тебя список тем с описаниями и источниками. Найди кластеры, которые относятся к одному событию или очень похожей теме.

**ПРАВИЛА ОБЪЕДИНЕНИЯ:**
- Объединяй кластеры об одном событии с разных ракурсов
- Объединяй похожие темы (например, "налоги" и "налоговая реформа")
- НЕ объединяй разные события одной тематики
- Учитывай географическую и временную близость

**КЛАСТЕРЫ ДЛЯ АНАЛИЗА:**
{clusters_text}

**ФОРМАТ ОТВЕТА:**
Верни JSON-массив объединенных кластеров. Каждый кластер должен содержать:
- "topic_summary": обновленное описание темы
- "sources": объединенный список всех источников
- "combined_context": скомбинированный общий текст

Если кластеры не похожи - оставь их отдельно.
```

Для корректной работы запросов требуется составной индекс:
- Коллекция: `news_clusters`
- Поля: `published` (по убыванию), `created_at` (по убыванию)

## 🔄 Интеграция с основным пайплайном

### Последовательность обработки:
1. **Парсинг RSS** → получение анонсов
2. **Фильтрация** → отбор интересных новостей
3. **Кластеризация** → группировка по темам (опционально)
4. **Обработка** → перевод и адаптация
5. **Публикация** → сохранение и отправка

### Режимы работы:
- **Обычный**: RSS → фильтрация → обработка → публикация
- **С кластеризацией**: RSS → фильтрация → кластеризация → обработка → публикация
- **Только кластеры**: получение из БД → обработка → публикация
