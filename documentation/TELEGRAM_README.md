# 📱 Генерация Telegram-постов

Новая функция для автоматической генерации Telegram-постов на основе обработанных статей с помощью LLM.

## ✨ Возможности

- **🤖 AI-генерация** - создание живых и информативных постов с помощью GPT-4o-mini
- **📏 Автоматическое ограничение** - посты автоматически обрезаются до 1000 символов
- **🎯 Целевая аудитория** - адаптировано для русскоязычных мигрантов в Испании
- **📱 Telegram-формат** - включает эмодзи и Markdown-разметку
- **🔄 Fallback-режим** - работает даже без OpenAI API
- **💾 Интеграция** - легко встраивается в существующую цепочку обработки

## 🚀 Быстрый старт

### 1. Установка

```bash
pip install python-telegram-bot==20.7
```

### 2. Использование

```python
from rss_parser import RSSParser

# Создаем парсер
parser = RSSParser()

# Обработанная статья
article = {
    "title": "Новые правила миграции в Испании",
    "description": "Описание статьи...",
    "content": "Полный текст статьи...",
    "tags": ["миграция", "Испания"],
    "slug": "migration-rules-2025"
}

# Генерируем Telegram-пост
telegram_post = parser.generate_telegram_post(article)
print(telegram_post)
```

### 3. Отправка в Telegram

```python
import asyncio
import telegram

async def send_post():
    bot = telegram.Bot(token='YOUR_BOT_TOKEN')
    await bot.send_message(
        chat_id='@your_channel',
        text=telegram_post,
        parse_mode='Markdown'
    )

asyncio.run(send_post())
```

## 📱 Формат постов

Сгенерированные посты имеют структуру:

```
🧲 Заголовок статьи

🧾 Основной текст (3-6 абзацев)
с ключевой информацией и деталями

🔗 Ссылка на полную статью: https://example.com/news/slug/

💬 Призыв к обсуждению в комментариях
```

## 🔄 Интеграция в цепочку

```python
# После обработки статьи
processed_article = parser.process_article(original_article)

if processed_article:
    # Сохраняем в Firebase
    parser.save_to_firebase(original_article, processed_article)
    
    # Генерируем Telegram-пост
    telegram_post = parser.generate_telegram_post(processed_article)
    
    # Отправляем в Telegram
    await bot.send_message(
        chat_id=channel_id,
        text=telegram_post,
        parse_mode='Markdown'
    )
```

- **Автоматическая обрезка** - посты длиннее 1000 символов автоматически обрезаются
- **Fallback-режим** - создает простые посты без OpenAI API
- **Обработка ошибок** - подробное логирование и обработка исключений
- **Markdown-форматирование** - поддержка эмодзи и разметки
- **Адаптация контента** - специально для русскоязычных мигрантов в Испании
