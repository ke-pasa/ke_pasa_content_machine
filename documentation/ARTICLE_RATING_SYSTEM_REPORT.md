## 🎨 **LLM-промпт для оценки статей**

### **Системный промпт:**
```
Ты редактор телеграм-новостей. Оцени пригодность материала для короткого, ёмкого поста. Строго JSON.
```

### **Пользовательский промпт:**
```
Статья (русский текст):

TITLE: {title}
DESCRIPTION: {description}
CATEGORY: {category}
PRIORITY_SCORE: {priority_score}    # 0..100
URGENT: {urgent}                    # true/false

СУТЬ (первые 1200 символов контента):
{content[:1200]}

Оцени по шкале 0..1:
- usefulness: практическая польза для жизни в Испании (деньги/правила/безопасность/что делать).
- emotional_hook: вызывает интерес, эмоцию, спор, риск, конфликт, «что делать сейчас».
- can_fit_1000: true/false — можно ли уложить читаемую суть в 900–1000 символов.
- bullets: дай 2–4 предельно коротких тезиса по сути (не более 12 слов каждый).

Ответ ТОЛЬКО JSON:
{ "usefulness":0.0, "emotional_hook":0.0, "can_fit_1000":true, "bullets":["...","..."] }
```

## 📊 **Формула расчета рейтинга**

### **Компоненты рейтинга:**
```python
score = (
    weights['priority'] * priority_score +      # 40% - базовый приоритет
    weights['usefulness'] * usefulness +       # 25% - практическая польза
    weights['emotional'] * emotional_hook +    # 20% - эмоциональность
    weights['recency'] * recency +             # 10% - актуальность
    weights['snack'] * snack                   # 5%  - "закусочность"
) * 100
```

### **Детали расчета:**
- **priority_score**: Нормализованный к 0..1 базовый приоритет статьи
- **usefulness**: LLM-оценка практической пользы (0..1)
- **emotional_hook**: LLM-оценка эмоциональности (0..1)
- **recency**: Экспоненциальное затухание актуальности (0..1)
- **snack**: Оценка возможности упаковать в 1000 символов (1.0 или 0.5)

## 🚀 **Логика публикации**

### **Urgent статьи:**
- Публикуются сразу, игнорируя расписание
- Не тратят дневной лимит
- Обходят cooldown категорий

### **Обычные статьи:**
- Публикуются в активных окнах
- Соблюдают дневной лимит
- Применяется cooldown категорий (90 минут)

### **Микро-правила:**
- Не постим подряд 2 новости одной категории
- Если `can_fit_1000 == false`, генерируем короткую версию
- Используем `bullets` для структурирования постов
